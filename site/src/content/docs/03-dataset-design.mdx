良いプロンプトは正解を教えるものではなく、役割、安全境界、参照すべき入力、判断規則、出力契約を明確にします。ケース固有の金額は書きません。

<Steps>

1. ### Agentプロンプトを作る

   `workshop/manual/prompts/agent-v1.md`を作ります。

   <FileCreate path="workshop/manual/prompts/agent-v1.md" lang="markdown" code={fileContent1} />

2. ### 出力Schemaを用意する

   教材のSchemaを実習用へコピーし、JSONとして読めることを確認します。

   <Command title="出力契約を準備">

   ```bash
   cp schemas/agent-output.schema.json \
     workshop/manual/schemas/agent-output.schema.json
   python -m json.tool \
     workshop/manual/schemas/agent-output.schema.json > /dev/null
   ```

   </Command>

   <ConsoleStep title="Schemaで固定するもの" label="CONTRACT">

   | field | 目的 |
   |---|---|
   | `status` | 計算完了／質問／非対応／エラーを区別 |
   | `service_estimates` | サービス、数量、単価、式、根拠を機械検査 |
   | `monthly_total_usd` | oracle範囲と内訳合計を比較 |
   | `missing_inputs` | 情報不足を自然文ではなく安定IDで比較 |
   | `assumptions` / `excluded_costs` | Judgeが読む意味品質を分離 |

   </ConsoleStep>

3. ### trialへ見せるファイルだけを配置する

   まず情報不足ケースの1回目を準備します。

   <Command title="trial-01 workspaceを作成">

   ```bash
   trial=workshop/manual/runs/no-mcp/cfn-missing-usage/trial-01
   mkdir -p "$trial/input"
   cp workshop/manual/cases/cfn-missing-usage/case-public.json \
     "$trial/case-public.json"
   cp workshop/manual/cases/cfn-missing-usage/input/template.yaml \
     "$trial/input/template.yaml"
   cp workshop/manual/schemas/agent-output.schema.json \
     "$trial/agent-output.schema.json"
   cp workshop/manual/prompts/agent-v1.md "$trial/TASK.md"
   ```

   </Command>

   `oracle.json`はコピーしません。採点側は元のケースディレクトリから読みます。

4. ### プロンプトをレビューする

   次の3つを人が確認します。

   - 正解の金額、expected status、必須IDが混ざっていない
   - MCPの有無と権限が実験条件と一致している
   - 「詳しく答える」ではなく、観察可能な出力要件になっている

</Steps>

<Aside type="tip" title="長さより判断規則">
  例文を増やしすぎると、その表現を再現するテストになります。曖昧な場面で「計算・質問・停止」のどれを選ぶかを明示し、ケース固有の正解は隠します。
</Aside>

<ExpectedResult>

Agentが読む`TASK.md`、`case-public.json`、`input/`、`agent-output.schema.json`だけを持つ、oracleなしのtrial workspaceが完成しています。

</ExpectedResult>

<Checkpoint>

- [ ] promptに役割・安全・判断規則・出力契約がある
- [ ] JSON Schemaで機械判定できる形にした
- [ ] trial workspaceへoracleをコピーしていない
- [ ] MCPなしのときtoolを捏造しない指示がある

</Checkpoint>
