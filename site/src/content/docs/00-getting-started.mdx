<TaskMeta time="10分" credentials="Agent CLI認証のみ" cost="$0（実行前）" />

このWorkshopでは、リポジトリ付属の専用評価コマンドを使いません。受講者自身がケース、プロンプト、実行workspace、判定コードを作り、CodexまたはClaude Codeを直接呼び出します。

<Aside type="note" title="必要なもの">
  Git、Python 3.11以降、JSONを編集できるエディタ、Codex CLIまたはClaude Codeが必要です。MCP章では追加で`uv`とAWSの短期認証を使います。
</Aside>

<Steps>

1. ### リポジトリを取得する

   <Command title="教材を取得">

   ```bash
   git clone https://github.com/tsuji-tomonori/aws-agent-test.git
   cd aws-agent-test
   ```

   </Command>

2. ### 使用するAgent CLIを確認する

   <Tabs>
     <TabItem label="Codex">
       <Command title="Codexを確認">

       ```bash
       codex --version
       codex login status
       ```

       </Command>
     </TabItem>
     <TabItem label="Claude Code">
       <Command title="Claude Codeを確認">

       ```bash
       claude --version
       claude auth status
       ```

       </Command>
     </TabItem>
   </Tabs>

   認証はAgent CLIの推論に使うもので、AWS認証とは別です。CLIのバージョンと利用モデルは実験記録へ残します。

3. ### 手作り評価の作業場所を作る

   <Command title="実習ディレクトリを準備">

   ```bash
   mkdir -p workshop/manual/{cases,prompts,schemas,runs,scripts}
   python --version
   ```

   </Command>

   この配下へ、以降の章で次の成果物を作ります。

   ```text
   workshop/manual/
   ├── cases/       # 公開入力と、別管理するoracle
   ├── prompts/     # Agent用とJudge用
   ├── schemas/     # 機械判定する出力契約
   ├── runs/        # trialごとの入力・出力・判定
   └── scripts/     # 自分で内容を確認して作る短い採点コード
   ```

4. ### 認証境界を決める

   最初のケースはAWS認証なしで実行します。AWS Pricing MCPは第4章まで追加しません。シェルにデプロイ可能なAWS profileが残っている場合は、別ターミナルまたは資格情報のない環境で進めます。

</Steps>

<ExpectedResult>

`python`と選んだAgent CLIのバージョンが表示され、`workshop/manual/`の5ディレクトリが作成されています。この時点でAWS APIは呼びません。

</ExpectedResult>

<Checkpoint>

- [ ] 専用評価CLIを使わない実習であることを理解した
- [ ] Agent CLIとモデルを記録した
- [ ] AWS認証とAgent CLI認証を区別した
- [ ] `runs/`へ秘密情報やoracleをコピーしない方針を決めた

</Checkpoint>
