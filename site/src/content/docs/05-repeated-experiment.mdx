<TaskMeta time="25分" level="中級" credentials="Agent CLI認証" cost="1 trial分の推論費用" />

まず`cfn-missing-usage`をMCPなしで1回だけ実行します。反復を始める前に、入力、出力、終了状態、採点理由を人が追えることを確認します。

<Steps>

1. ### Agent CLIを直接呼ぶ

   Claude Codeを選ぶ場合だけ、次の補助スクリプトを先に作成します。[公式仕様](https://code.claude.com/docs/en/headless#get-structured-output)ではJSON結果の`structured_output`に回答が入るため、これを`answer.json`へ取り出します。

   <FileCreate path="workshop/manual/scripts/extract_claude.py" lang="python" code={extractClaude} />

   第4章でMCPを登録済みでも、ここでは無効にします。Codexは`aws-pricing`を無効化します。他の登録済みMCPがないことも`codex mcp list`で確認してください。Claude Codeは空の明示設定だけを読み込みます。

   <Tabs>
     <TabItem label="Codex">
       <Command title="trial-01を実行" prompt="READ ONLY">

       ```bash
       pricing_disable=()
       if codex mcp get aws-pricing > /dev/null 2>&1; then
         pricing_disable=(-c mcp_servers.aws-pricing.enabled=false)
       fi
       trial=workshop/manual/runs/no-mcp/cfn-missing-usage/trial-01
       (
         cd "$trial"
         codex exec --ephemeral --sandbox read-only \
           "${pricing_disable[@]}" \
           --output-schema agent-output.schema.json \
           --output-last-message answer.json \
           - < TASK.md
       )
       ```

       </Command>

       `--ephemeral`で会話履歴を永続化せず、`--sandbox read-only`でファイル変更を許可しません。`--output-schema`は最終回答をJSON契約へ制約します。
     </TabItem>
     <TabItem label="Claude Code">
       <Command title="trial-01を実行" prompt="READ ONLY">

       ```bash
       trial=workshop/manual/runs/no-mcp/cfn-missing-usage/trial-01
       (
         cd "$trial"
         claude -p --max-turns 24 --output-format json \
           --strict-mcp-config --mcp-config '{"mcpServers":{}}' \
           --no-session-persistence \
           --permission-mode dontAsk \
           --tools "Read,Glob,Grep" \
           --json-schema "$(cat agent-output.schema.json)" \
           "$(cat TASK.md)" > claude-result.json
       ) && python workshop/manual/scripts/extract_claude.py \
         "$trial/claude-result.json" "$trial/answer.json"
       ```

       </Command>

       `--no-session-persistence`で会話を保存せず、`--tools`で読み取り系toolだけを公開します。`dontAsk`により未許可toolは対話待ちにせず拒否し、`--output-format json`と`--json-schema`で構造化結果を取得します。生の結果は`claude-result.json`、取り出した回答は`answer.json`です。
     </TabItem>
   </Tabs>

2. ### 出力を開く

   <Command title="JSONと主要fieldを確認">

   ```bash
   python -m json.tool \
     workshop/manual/runs/no-mcp/cfn-missing-usage/trial-01/answer.json
   ```

   </Command>

   このケースの期待は金額ではなく、`status=needs_clarification`と5個の不足IDです。もっともらしい月額を返していたら失敗です。

3. ### 決定的チェッカーを自分で作る

   `workshop/manual/scripts/check_result.py`を作ります。第0章で入れた`jsonschema`で型・必須項目も検証します。AWS操作やファイル変更の有無は、この回答チェッカーだけでは証明できないため実行ログと権限を別途確認します。

   <FileCreate path="workshop/manual/scripts/check_result.py" lang="python" code={fileContent1} />

4. ### oracleを外側から渡して採点する

   <Command title="決定的ゲートを実行">

   ```bash
   python workshop/manual/scripts/check_result.py \
     workshop/manual/runs/no-mcp/cfn-missing-usage/trial-01/answer.json \
     workshop/manual/cases/cfn-missing-usage/oracle.json \
     > workshop/manual/runs/no-mcp/cfn-missing-usage/trial-01/verdict.json
   cat workshop/manual/runs/no-mcp/cfn-missing-usage/trial-01/verdict.json
   ```

   </Command>

   oracleはAgent workspaceへ配置せず、採点processだけへ明示的に渡します。ディレクトリを分けるだけではOSの読み取り制限にはなりません。厳密なholdoutでは公開入力だけをマウントした隔離環境を使います。

5. ### MCPありケースを1回pilotする

   第4章を完了した場合だけ、`cfn-static-site`を別の実験条件で実行します。

   <Tabs>
     <TabItem label="Codex">
       <Command title="Pricing MCP pilotを準備・実行" prompt="BASH">

       ```bash
       case_dir=workshop/manual/cases/cfn-static-site
       trial=workshop/manual/runs/pricing-mcp/cfn-static-site/trial-01
       mkdir -p "$trial/input"
       cp "$case_dir/case-public.json" "$trial/case-public.json"
       cp "$case_dir/input/template.yaml" "$trial/input/template.yaml"
       cp workshop/manual/prompts/agent-v1.md "$trial/TASK.md"
       cp workshop/manual/schemas/agent-output.schema.json "$trial/agent-output.schema.json"
       (
         cd "$trial"
         codex exec --ephemeral --sandbox read-only --json \
           -c mcp_servers.aws-pricing.enabled=true \
           --output-schema agent-output.schema.json \
           --output-last-message answer.json \
           - < TASK.md > events.jsonl
       )
       python workshop/manual/scripts/check_result.py \
         "$trial/answer.json" "$case_dir/oracle.json" > "$trial/verdict.json"
       cat "$trial/verdict.json"
       ```

       </Command>
     </TabItem>
     <TabItem label="Claude Code">
       <Command title="Pricing MCP pilotを準備・実行" prompt="BASH">

       ```bash
       case_dir=workshop/manual/cases/cfn-static-site
       trial=workshop/manual/runs/pricing-mcp/cfn-static-site/trial-01
       mkdir -p "$trial/input"
       cp "$case_dir/case-public.json" "$trial/case-public.json"
       cp "$case_dir/input/template.yaml" "$trial/input/template.yaml"
       cp workshop/manual/prompts/agent-v1.md "$trial/TASK.md"
       cp workshop/manual/schemas/agent-output.schema.json "$trial/agent-output.schema.json"
       mcp_config="$(pwd)/workshop/manual/config/pricing-mcp.json"
       (
         cd "$trial"
         claude -p --max-turns 24 --output-format json \
           --no-session-persistence --permission-mode dontAsk \
           --tools "Read,Glob,Grep" --allowedTools "mcp__aws-pricing__*" \
           --strict-mcp-config --mcp-config "$mcp_config" \
           --json-schema "$(cat agent-output.schema.json)" \
           "$(cat TASK.md)" > claude-result.json
       ) && python workshop/manual/scripts/extract_claude.py \
         "$trial/claude-result.json" "$trial/answer.json"
       python workshop/manual/scripts/check_result.py \
         "$trial/answer.json" "$case_dir/oracle.json" > "$trial/verdict.json"
       cat "$trial/verdict.json"
       ```

       </Command>
     </TabItem>
   </Tabs>

   MCP tool call、根拠URL、単価、式を確認してから反復へ進みます。既に実行済みのpilotを再実行せず、回答ファイルとログを保持してください。

</Steps>

<Aside type="caution" title="失敗を直ちに再実行しない">
  timeout、MCP未接続、Schema違反、対象漏れを分類してから修正します。成功するまで同じtrialをやり直すと、失敗率を隠してしまいます。
</Aside>

</ExpectedResult>
