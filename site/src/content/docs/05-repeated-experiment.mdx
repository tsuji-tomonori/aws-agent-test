<Steps>

1. ### Agent CLIを直接呼ぶ

   <Tabs>
     <TabItem label="Codex">
       <Command title="trial-01を実行" prompt="READ ONLY">

       ```bash
       trial=workshop/manual/runs/no-mcp/cfn-missing-usage/trial-01
       (
         cd "$trial"
         codex exec --ephemeral --sandbox read-only \
           --output-schema agent-output.schema.json \
           --output-last-message answer.json \
           - < TASK.md
       )
       ```

       </Command>

       `--ephemeral`で会話履歴を永続化せず、`--sandbox read-only`でファイル変更を許可しません。`--output-schema`は最終回答をJSON契約へ制約します。
     </TabItem>
     <TabItem label="Claude Code">
       <Command title="trial-01を実行" prompt="READ ONLY">

       ```bash
       trial=workshop/manual/runs/no-mcp/cfn-missing-usage/trial-01
       (
         cd "$trial"
         claude -p --max-turns 24 \
           --no-session-persistence \
           --permission-mode dontAsk \
           --tools "Read,Glob,Grep" \
           --json-schema "$(cat agent-output.schema.json)" \
           "$(cat TASK.md)" > answer.json
       )
       ```

       </Command>

       `--no-session-persistence`で会話を保存せず、`--tools`で読み取り系toolだけを公開します。`dontAsk`により未許可toolは対話待ちにせず拒否し、`--json-schema`で最終JSONを検証して`answer.json`へ保存します。
     </TabItem>
   </Tabs>

3. ### 決定的チェッカーを自分で作る

   `workshop/manual/scripts/check_result.py`を作ります。判定内容が読める短いコードにします。

   ```python
   import json
   import sys
   from pathlib import Path

   result = json.loads(Path(sys.argv[1]).read_text(encoding="utf-8"))
   oracle = json.loads(Path(sys.argv[2]).read_text(encoding="utf-8"))
   errors: list[str] = []

   if result.get("status") != oracle["expected_status"]:
       errors.append("status mismatch")

   required_services = set(oracle.get("required_services", []))
   actual_services = {
       item.get("service") for item in result.get("service_estimates", [])
   }
   if not required_services <= actual_services:
       errors.append("required service missing")

   required_missing = set(oracle.get("required_missing_input_ids", []))
   actual_missing = {item.get("id") for item in result.get("missing_inputs", [])}
   if not required_missing <= actual_missing:
       errors.append("required clarification missing")

   expected_total = oracle.get("monthly_total_usd")
   if expected_total:
       total = result.get("monthly_total_usd")
       if not isinstance(total, (int, float)):
           errors.append("monthly total missing")
       elif not expected_total["minimum"] <= total <= expected_total["maximum"]:
           errors.append("monthly total outside oracle range")

       subtotal = sum(
           item.get("monthly_cost_usd", 0)
           for item in result.get("service_estimates", [])
       )
       if isinstance(total, (int, float)) and abs(total - subtotal) > 0.02:
           errors.append("service subtotal mismatch")

   required_urls = set(oracle.get("required_source_urls", []))
   actual_urls = {
       source.get("url")
       for item in result.get("service_estimates", [])
       for source in item.get("sources", [])
   }
   if not required_urls <= actual_urls:
       errors.append("required source missing")

   print(json.dumps({"passed": not errors, "errors": errors}, ensure_ascii=False))
   raise SystemExit(1 if errors else 0)
   ```

4. ### oracleを外側から渡して採点する

   <Command title="決定的ゲートを実行">

   ```bash
   python workshop/manual/scripts/check_result.py \
     workshop/manual/runs/no-mcp/cfn-missing-usage/trial-01/answer.json \
     workshop/manual/cases/cfn-missing-usage/oracle.json
   ```

   </Command>

   Agent workspaceからはoracleを読めませんが、採点processは明示的に2ファイルを受け取ります。

5. ### MCPありケースを1回pilotする

   第4章を完了した場合だけ、`cfn-static-site`を別の実験条件で実行します。

   <Command title="Pricing MCP pilotを準備・実行" prompt="PRICING MCP / READ ONLY">

   ```bash
   case_dir=workshop/manual/cases/cfn-static-site
   trial=workshop/manual/runs/pricing-mcp/cfn-static-site/trial-01
   mkdir -p "$trial/input"
   cp "$case_dir/case-public.json" "$trial/case-public.json"
   cp "$case_dir/input/template.yaml" "$trial/input/template.yaml"
   cp workshop/manual/prompts/agent-v1.md "$trial/TASK.md"
   cp workshop/manual/schemas/agent-output.schema.json \
     "$trial/agent-output.schema.json"

   (
     cd "$trial"
     codex exec --ephemeral --sandbox read-only --json \
       --output-schema agent-output.schema.json \
       --output-last-message answer.json \
       - < TASK.md > events.jsonl
   )

   python workshop/manual/scripts/check_result.py \
     "$trial/answer.json" "$case_dir/oracle.json"
   ```

   </Command>

   Claude Codeの場合は最初のAgent呼び出しと同じ安全flagを使い、Pricing MCPのtoolだけを`--allowedTools "mcp__aws-pricing__*"`で追加許可します。MCP tool call、根拠URL、単価、式、出力先外への書き込みがないことを確認してから反復へ進みます。

</Steps>

<Aside type="caution" title="失敗を直ちに再実行しない">
  timeout、MCP未接続、Schema違反、対象漏れを分類してから修正します。成功するまで同じtrialをやり直すと、失敗率を隠してしまいます。
</Aside>
