## 直接実行の最小形

```bash
codex exec --ephemeral --sandbox read-only \
  --output-schema agent-output.schema.json \
  --output-last-message answer.json \
  - < TASK.md
```

この1回を新しいworkspaceで繰り返し、外側のPython checkerへ`answer.json`と`oracle.json`を渡します。専用評価CLIは使いません。

<Checkpoint title="実行前の30秒確認">

- [ ] Agent workspaceにoracleがない
- [ ] AWS変更権限がない
- [ ] MCPの有無がexperiment IDと一致する
- [ ] 前回sessionをresumeしない
- [ ] 出力先、trial数、費用上限を決めた
- [ ] 不合格をJudgeで上書きしない

</Checkpoint>

<Aside type="caution" title="保存しないもの">
  AWSやAgentの資格情報、秘密を含むtranscript、生成された一時認証、MCP cache、個人のglobal設定ファイルはリポジトリへcommitしません。
</Aside>
