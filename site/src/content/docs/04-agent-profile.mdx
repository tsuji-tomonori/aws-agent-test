<TaskMeta time="20分" level="中級" credentials="短期AWS認証（pricingのみ）" cost="Pricing APIは無料／推論費用あり" />

この章は任意です。MCPを使わない`no-mcp`実験と、AWS Pricing MCPを使う`pricing-mcp`実験は別条件です。接続前に、MCPなしの条件名とpromptを保存してください。

<Aside type="danger" title="デプロイ権限を渡さない">
  使用するのは[AWS Pricing MCP Server](https://awslabs.github.io/mcp/servers/aws-pricing-mcp-server)です。AWS API MCPやデプロイ系toolは追加せず、専用の短期profileへ`pricing:*`だけを付与します。
</Aside>

<Steps>

1. ### IAM境界を確認する

   評価専用roleまたはpermission setには、価格参照以外を含めません。以下は**管理者へ渡すポリシー見本**をローカルに保存する手順です。保存だけではIAMへ適用されません。既に用意された価格参照専用の短期profileを使ってください。

   <FileCreate path="workshop/manual/config/pricing-policy.json" lang="json" code={fileContent1} />

   この教材ではprofile名を`agent-pricing-eval`に統一します。管理者が用意した同名のSSO profileで、次を実行します。profileが未設定なら先に管理者へ依頼してください。

   <Command title="用意済みSSO profileへログイン" prompt="BASH">

   ```bash
   aws sso login --profile agent-pricing-eval
   ```

   </Command>

2. ### MCP serverを登録する

   事前に`uv`とPython 3.10以降を用意します。AWS公式手順は`uvx awslabs.aws-pricing-mcp-server@latest`を使用します。

   <Tabs>
     <TabItem label="Codex">
       [CodexのMCP設定](https://developers.openai.com/codex/mcp)に従い、stdio serverを登録します。

       <Command title="CodexへAWS Pricing MCPを追加" prompt="LOCAL MCP">

       ```bash
       mkdir -p workshop/manual/runs/mcp-output
       codex mcp add aws-pricing \
         --env AWS_PROFILE=agent-pricing-eval \
         --env AWS_REGION=us-east-1 \
         --env FASTMCP_LOG_LEVEL=ERROR \
         --env AWS_PRICING_MCP_OUTPUT_DIR="$(pwd)/workshop/manual/runs/mcp-output" \
         -- uvx awslabs.aws-pricing-mcp-server@latest

       codex mcp list
       ```

       </Command>
     </TabItem>
     <TabItem label="Claude Code">
       [Claude CodeのMCP設定](https://docs.anthropic.com/en/docs/claude-code/mcp)では、server引数を`--`の後ろへ置きます。

       <Command title="Claude CodeへAWS Pricing MCPを追加" prompt="LOCAL MCP">

       ```bash
       mkdir -p workshop/manual/runs/mcp-output
       claude mcp add --scope local --transport stdio \
         --env AWS_PROFILE=agent-pricing-eval \
         --env AWS_REGION=us-east-1 \
         --env FASTMCP_LOG_LEVEL=ERROR \
         --env AWS_PRICING_MCP_OUTPUT_DIR="$(pwd)/workshop/manual/runs/mcp-output" \
         aws-pricing -- uvx awslabs.aws-pricing-mcp-server@latest

       claude mcp list
       ```

       </Command>
     </TabItem>
   </Tabs>

   WindowsネイティブではAWS公式手順に従い、server commandを`uvx --from awslabs.aws-pricing-mcp-server@latest awslabs.aws-pricing-mcp-server.exe`へ置き換えます。WSLではLinux側の例を使います。

3. ### 接続とtoolを確認する

   Agent CLIを対話起動し、`/mcp`を開きます。`aws-pricing`がconnectedで、価格検索系toolだけが見えることを確認します。

   <ConsoleStep title="接続確認プロンプト" label="SMOKE TEST">

   AWS Pricing MCPで利用可能なtool名を列挙してください。価格の検索やレポート生成はまだ実行しないでください。

   </ConsoleStep>

   serverが起動できない場合は、`uvx`、短期認証の期限、`AWS_PROFILE`、`AWS_REGION`、`pricing:*`を確認します。CloudFormationやIAM変更権限を追加して解決しません。

4. ### 実験条件を更新する

   元の`workshop/manual/experiment.json`を読み、全項目を保持したまま`workshop/manual/experiment-pricing-mcp.json`を生成します。同時にClaude Codeの明示設定`workshop/manual/config/pricing-mcp.json`も作ります。下のスクリプトを保存して実行してください。

   <FileCreate path="workshop/manual/scripts/prepare_mcp.py" lang="python" code={fileContent2} />

   先に次のコマンドで表示されたバージョンを控えます。続くスクリプトの入力欄へ、その値を入力してください。

   <Command title="使用するMCP packageの版を確認" prompt="BASH">

   ```bash
   uvx --from awslabs.aws-pricing-mcp-server@latest python -c \
     "import importlib.metadata; print(importlib.metadata.version('awslabs.aws-pricing-mcp-server'))"
   ```

   </Command>

   <Command title="MCP実験条件を生成・確認" prompt="BASH">

   ```bash
   python workshop/manual/scripts/prepare_mcp.py
   python -m json.tool workshop/manual/experiment-pricing-mcp.json
   python -m json.tool workshop/manual/config/pricing-mcp.json
   ```

   </Command>

   Codexを使う場合は登録も同じ版へ更新します。Claude Codeの実行例は、生成した`pricing-mcp.json`を絶対パスで指定して使います。

   <Command title="Codexのみ：記録した版で登録を更新" prompt="BASH">

   ```bash
   mcp_package=$(python -c 'import json; print(json.load(open("workshop/manual/experiment-pricing-mcp.json"))["mcp_server"])')
   codex mcp add aws-pricing \
     --env AWS_PROFILE=agent-pricing-eval \
     --env AWS_REGION=us-east-1 \
     --env FASTMCP_LOG_LEVEL=ERROR \
     --env AWS_PRICING_MCP_OUTPUT_DIR="$(pwd)/workshop/manual/runs/mcp-output" \
     -- uvx "$mcp_package"
   ```

   </Command>

</Steps>

<ExpectedResult>

`aws-pricing`が接続済みで、AWS変更系toolが存在しません。MCPなし／ありの実験条件が別IDで保存されています。

</ExpectedResult>

<Checkpoint>

- [ ] AWS Pricing MCPの公式serverだけを追加した
- [ ] 短期認証と`pricing:*`だけを使った
- [ ] `AWS_PRICING_MCP_OUTPUT_DIR`を実習配下へ限定した
- [ ] `/mcp`で接続とtool一覧を確認した
- [ ] no-mcpとpricing-mcpを別実験にした

</Checkpoint>
