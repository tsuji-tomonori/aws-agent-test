## このWorkshopで作るもの

一つのプロンプトを試すだけではありません。評価対象を固定し、独立したtrialを繰り返し、**失敗してはいけない条件**と**説明品質**を分けて測る、小さな評価パイプラインを完成させます。

## 学習ゴール

完了時には、次の判断を自分の言葉で説明できるようになります。

- なぜ「モデル」ではなく、model + CLI + tools + prompt + permissions + dataset を評価するのか
- なぜcritical failureを平均スコアで相殺してはいけないのか
- なぜpass@kだけでなくpass^kを見るのか
- どの判定を決定的コードへ置き、どの判定をLLM Judgeへ残すのか
- live評価を始める前に、何をMockと1回のpilotで確かめるのか

<Checkpoint title="安全に進めるための前提">

このWorkshopの標準ルートはAWSリソースを作成しません。AWS認証情報も不要です。Live pilotは利用中のAgent CLI自体の認証と推論費用が発生し得るため、該当ページで明示的に分岐します。

</Checkpoint>
